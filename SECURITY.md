# Security policy

This repository contains experiment orchestration scripts that can execute
local commands when explicitly passed `--execute`. Review commands and paths
before running them on a machine with sensitive data or credentials.

Please report a security issue privately to the repository owner through the
GitHub private vulnerability reporting flow when available. Do not publish
working exploit details in a public issue.

The project does not provide a hosted inference endpoint. Reports about model
outputs, unsafe generations, or benchmark behavior should include the model
revision, runtime revision, prompt category, and reproduction command, while
redacting credentials and private data.
